CYBERSECURITY SEMANTIC SCHEMA DESCRIPTIONS

Total Elements: 30

================================================================================
NODE LABELS (14 total)
================================================================================

1. UcoCVE
   Common Vulnerabilities and Exposures - security vulnerabilities with unique identifiers (e.g., CVE-2023-1234)

2. UcoCWE
   Common Weakness Enumeration - software weakness types and categories (e.g., CWE-79 for XSS)

3. UcoExploitTarget
   Target systems or applications that can be exploited by vulnerabilities

4. UcoVulnerability
   Generic vulnerability information with publication and modification dates

5. UcoexCAMPAIGNS
   Cybersecurity campaigns - coordinated attack activities by threat groups

6. UcoexCAPEC
   Common Attack Pattern Enumeration and Classification - attack patterns and techniques used by adversaries

7. UcoexCPE
   Common Platform Enumeration - software and hardware products with standardized names (e.g., microsoft:windows)

8. UcoexGROUPS
   Threat actor groups and organizations conducting cyber attacks

9. UcoexMITIGATIONS
   Defensive techniques and countermeasures against attacks

10. UcoexMITREATTACK
   MITRE ATT&CK framework techniques, tactics, and procedures used by adversaries

11. UcoexMITRED3FEND
   MITRE D3FEND framework defensive techniques and countermeasures

12. UcoexObservedExample
   Real-world examples of vulnerabilities and attacks being observed

13. UcoexSOFTWARE
   Software applications and tools used in cybersecurity contexts

14. UcoexTACTICS
   MITRE ATT&CK tactics - high-level adversary goals and objectives

   Exploit target has specific vulnerability - connects targets to vulnerabilities

   Exploit target has specific weakness - connects targets to CWEs

8. UCOEXCAMPAIGNUSESTECHNIQUE
   Campaign employs specific attack technique - connects campaigns to techniques

9. UCOEXHASRELATEDWEAKNESS

10. UCOEXHASTAXONOMYMAPPING
   Attack pattern maps to specific MITRE technique - connects CAPECs to techniques

11. UCOEXGROUPUSESSOFTWARE
   Threat group uses specific software/tools - connects groups to software

12. UCOEXGROUPUSESTECHNIQUE
   Threat group employs specific attack technique - connects groups to techniques

13. UCOEXMITIGATES
   Mitigation technique counters specific attack - connects mitigations to techniques

14. UCOEXHASMITREATTACK
   D3FEND technique relates to specific MITRE technique - connects D3FEND to techniques

15. UCOEXEXAMPLEOBSERVEDIN
   Observed example is found in specific CVE - connects examples to CVEs

16. UCOEXSOFTWAREUSESTECHNIQUE
   Software uses specific attack technique - connects software to techniques
