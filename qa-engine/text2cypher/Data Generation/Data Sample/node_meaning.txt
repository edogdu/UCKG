================================================================================
NODE TYPES AND SEMANTIC DESCRIPTIONS
================================================================================

1. UcoCVE
   Semantic: Common Vulnerabilities and Exposures - security vulnerabilities with unique identifiers (e.g., CVE-2023-1234)

2. UcoCWE
   Semantic: Common Weakness Enumeration - software weakness types and categories (e.g., CWE-79 for XSS)

3. UcoExploitTarget
   Semantic: Target systems or applications that can be exploited by vulnerabilities

4. UcoVulnerability
   Semantic: Generic vulnerability information with publication and modification dates

5. UcoexCAMPAIGNS
   Semantic: Cybersecurity campaigns - coordinated attack activities by threat groups

6. UcoexCAPEC
   Semantic: Common Attack Pattern Enumeration and Classification - attack patterns and techniques used by adversaries

7. UcoexCPE
   Semantic: Common Platform Enumeration - software and hardware products with standardized names (e.g., microsoft:windows)

8. UcoexGROUPS
   Semantic: Threat actor groups and organizations conducting cyber attacks 

9. UcoexMITIGATIONS
   Semantic: Defensive techniques and countermeasures against attacks

10. UcoexMITREATTACK
   Semantic: MITRE ATT&CK framework techniques, tactics, and procedures used by adversaries
   
11. UcoexMITRED3FEND
   Semantic: MITRE D3FEND framework defensive techniques and countermeasures

12. UcoexObservedExample
   Semantic: Real-world examples of vulnerabilities and attacks being observed
   
13. UcoexSOFTWARE
   Semantic: Software applications and tools used in cybersecurity contexts
   
14. UcoexTACTICS
   Semantic: MITRE ATT&CK tactics - high-level adversary goals and objectives
