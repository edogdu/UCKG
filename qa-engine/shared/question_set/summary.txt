CWE-827, “Improper Control of Document Type Definition,” refers to a weakness where software fails to properly restrict the use or inclusion of external Document Type Definitions (DTDs) during XML processing. This flaw can allow attackers to reference unauthorized files, exhaust system resources, or trigger arbitrary network requests. In cybersecurity, this weakness is significant because it can lead to data exposure or denial-of-service attacks, particularly in systems that process XML, such as web services or APIs.
